# Alpine 3.24 (p08) – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (oder subagent-driven-development). Checkbox-Schritte (`- [ ]`).

**Goal:** Basis-Image auf `ghcr.io/home-assistant/base:3.24`, Start robust gegen bashio 0.19.0 (`inherit_errexit`), venv und alte Paketkopien sauber migriert, echtes Image in der CI gestartet.

**Architecture:** Alle Laufzeitänderungen in `claude-workbench/run.sh` (neue Funktionen `move_stale_persisted_libs`, `migrate_python_venv`, `check_persisted_alpine_release`, abgesicherte Option-Abfragen). Unit-Tests sourcen `run.sh` mit `CLAUDE_RUN_SH_SKIP_MAIN=true` und laufen unter denselben Shell-Optionen wie bashio 0.19.0. Image-Inhalt und echter Start werden nur in der CI geprüft (`tests/ci-boot-smoke.sh`).

**Tech Stack:** bash 5, bashio 0.19.0, Alpine 3.24, GitHub Actions, Docker Buildx.

**Spec:** `docs/specs/2026-11-05-alpine-3.24-design.md` · **Branch:** `chore/alpine-3.24` · **Vorlagen:** `git show a1f0f2da` (nsleigh), `git show 78d7b12f 2ec549c0 6641bfe0` (heytcass), `git show 4eaad373` (unsnow-iac), `git show d50e6c0d -- .github/workflows/build-test.yml` (heytcass).

## Global Constraints

- Temp nur unter `D:/Entwicklung/Claude-Code-HA/.tmp`. Vor jedem Testlauf: `export PATH="/c/WINDOWS/system32:$PATH" TMPDIR=D:/Entwicklung/Claude-Code-HA/.tmp TMP=D:/Entwicklung/Claude-Code-HA/.tmp TEMP=D:/Entwicklung/Claude-Code-HA/.tmp`.
- Lokal nur Einzelsuiten (`bash tests/<suite>.sh`, `node --test …`). `run-tests.sh` komplett und der Boot-Test laufen nur in der CI. **Kein Podman/Docker lokal.**
- Shell: 4 Leerzeichen Einrückung, `bashio::log.*` für Meldungen, Kommentare nach Skill `code-doku` (Wurzel, Fix, verworfene Alternative).
- Jede neue Funktion in `run.sh` muss unter `set -euo pipefail` **und** `shopt -s inherit_errexit` durchlaufen, ohne abzubrechen. Kein Befehl darf außerhalb von `if`/`||`/`&&` scheitern können (`cmp`, `grep`, leere Globs, fehlende Dateien).
- Default-Werte der Option-Abfragen exakt wie in der Tabelle in Spec E2.
- Marker `/data/packages/.alpine-release` enthält `X.Y`. Ohne Marker gilt `3.21`. Quarantäne-Ordner `/data/packages/stale-alpine-<alt>/lib/`. Wiederholungsliste `/data/packages/python/.reinstall-pending` (ein Paketname pro Zeile).
- Test-Nahtstellen (nur für Tests): `PERSIST_ROOT` (Default `/data/packages`), `SYSTEM_ROOT` (Default leer = `/`), `ALPINE_RELEASE_FILE` (Default `/etc/alpine-release`), `PERSIST_VENV` (Default `/data/packages/python/venv`), `PYTHON_BIN` (Default `python3`).
- Ein Commit pro grünem Task, gezielt stagen, danach `git show --stat --oneline HEAD`. Letzte Zeile jeder Message: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Credits im Commit-Body, wo etwas übernommen ist.
- Runner `ubuntu-24.04`. Push, PR, Merge, Tag nur nach Freigabe im Chat. `gh` immer mit `--repo Eifel-Joe/claude-workbench`.

## Review Focus

1. **Start ohne Netz beim ersten 3.6.0-Start:** Alle Neuinstallationen scheitern → `.reinstall-pending` bleibt vollständig, `migrate_python_venv` gibt 0 zurück, das Terminal startet. (Test in Task 3.)
2. **Neue Funktionen unter bashio-Optionen:** `cmp` mit Exit 1, leerer `lib`-Ordner, fehlender Marker, fehlende `/etc/alpine-release` dürfen `run.sh` nicht beenden. (Alle Tests in Task 2/3 laufen unter `set -euo pipefail; shopt -s inherit_errexit`.)
3. **Leerer Startbefehl:** `get_claude_launch_command` liefert bei scheiternden Optionen nie eine leere Zeichenkette. (Task 1.)
4. **Paketnamen aus METADATA mit `\r` oder Leerzeilen in der Liste:** werden bereinigt, keine leeren `pip install`-Aufrufe. (Task 3.)
5. **`persist-install --ha-cli`-Binary:** `bin/ha` mit `bin/.ha-version` wird nie als veraltet gemeldet oder verschoben. (Task 2.)
