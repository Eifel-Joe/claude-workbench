# Runde 3.6.4 – Umsetzungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (Native: diese Sitzung setzt um, am Ende ein Opus-Review des ganzen Branches). Checkbox-Schritte (`- [ ]`).

**Goal:** n30 „Paketnamen aus den Optionen prüfen, bevor die Installation sie bekommt“, n31 „Statuszeile und Plugin-Schalter bei der Daten-Übernahme aus der alten App mitnehmen“, n32 „Statuszeile: Auffrischen von Hand soll warten, wenn gerade eine Auffrischung läuft“, n33 „Übernahme-Angebot, das erst nach dem Einrichten von Statuszeile und Plugin entsteht“ – als Version 3.6.4.

**Architecture:** `persist-install` bekommt die Betriebsart `--apk`; `auto_install_packages` (`run.sh`) und die Übernahme (`scripts/app-migration/`) prüfen Namen aus Optionen und rufen apk nur mit `--apk`. Übernahme nimmt `statusline`/`home_assistant_plugin` (und, falls freigegeben, `enable_remote_control`) mit. `ha-statusline --refresh` wartet auf eine laufende Auffrischung, der Hintergrund nutzt `--refresh-background`. Eine Merkdatei `/data/migration/undecided` hält Statuszeile und Plugin zurück, solange die Erkennung nicht entschieden hat.

**Tech Stack:** bash 5 + bashio 0.19.0 (Alpine 3.24), jq, Node 24 (`node:test`), Claude Code CLI.

**Spec:** `docs/specs/2026-11-06-round-3.6.4-design.md` · **Branch:** `fix/round-3.6.4` · **Vorlage n30:** `git show 08686e1e 83c6997e -- claude-terminal/run.sh`
