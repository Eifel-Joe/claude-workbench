## Status line and Home Assistant plugin

- **A status line under Claude's input.** Line one: model, context left, folder and your plan limits. Line two: what in your home needs a look — smoke/gas/CO/water alerts, Supervisor repairs, broken automations, an old backup, a full disk, a new Home Assistant version, pending updates, weak batteries — or just `🏠 ✓`. It reads Home Assistant in the background at most every 30 seconds and never waits for it. Choose your own pieces with the new `statusline` option; a status line you set with `/statusline` is never replaced. The Supervisor token only ever goes to the Supervisor.
- **The Home Assistant plugin for Claude comes with the app.** `homeassistant-config` 2.1.4 is installed on the first start, without the network: Claude writes current Home Assistant syntax, checks every YAML file it edits and gets `/ha-check`, `/ha-upgrade` and `/ha-find-duplicates`. Turn it off with the new `home_assistant_plugin` option or with `/plugin`; an update keeps your choice.
- **Your own programs can't break the panel.** The app's start and services now use the system's programs first; in the terminal your `persist-install` programs still come first.
- **No more "null".** An option missing from the configuration no longer reads as the word `null` (e.g. as the Remote Control session name).

**Upgrade notes:** both new features are on by default. If the app offers to take over data from an older app on this start, status line and plugin are set up on the next start, so your old `settings.json` comes across first. Check the log for `Home Assistant plugin: installed 2.1.4` and `Home Assistant status line enabled` (or `keeping your own`).
